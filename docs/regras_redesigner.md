EGRAS OBRIGATÓRIAS PARA O DESENVOLVIMENTO

1. Antes de modificar qualquer arquivo, analisar a estrutura atual do frontend e o AGENTS.md.
2. Não modificar o backend Django.
3. Não alterar endpoints, modelos, serializers ou regras de negócio.
4. Não modificar autenticação, contexto de autenticação ou proteção de rotas.
5. Não remover campos, filtros, validações ou funcionalidades existentes.
6. Não utilizar dados mockados para substituir informações reais da API.
7. Não criar componentes duplicados sem necessidade.
8. Seguir a identidade visual e os componentes compartilhados.
9. Evitar modificar os mesmos arquivos simultaneamente.
10. Informar quais arquivos foram modificados e quais testes foram realizados.
